# Food data attribution

Contains information from [Open Food Facts](https://world.openfoodfacts.org),
made available under the [Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
Individual database contents use the [Database Contents License](https://opendatacommons.org/licenses/dbcl/1-0/).
Community data can be incomplete or incorrect; check product packaging when needed.

The app displays compact source/license links in Add Food. Preserve these notices
and the source metadata in future Data Sources/About, exports and shared data.
Publicly reused output needs associated attribution and a license link. Public
redistribution of a database must preserve its notices/license; publicly used
derivative databases carry ODbL share-alike and machine-readable access obligations
(ODbL sections 4.2–4.6). This is a database license, not a blanket requirement to
license the mobile application's source code or publish private diary records.
Before public catalog caching/merging/export, review which data is a derivative
versus a collective database and comply with the corresponding terms.

OFF product photographs have a separate CC BY-SA license and may contain other
rights. No photographs are requested, bundled, cached or displayed in TASK 20.
If introduced later, retain image attribution and review applicable image terms.

[Official OFF license guidance](https://openfoodfacts.github.io/documentation/docs/Product-Opener/api/tutorials/license-be-on-the-legal-side/)
and [terms of use/reuse](https://world.openfoodfacts.org/terms-of-use).
